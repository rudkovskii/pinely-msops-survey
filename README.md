## Как сохраняются ответы

Восемь вопросов по четырём блокам сессии (база, данные и безопасность, автоматизация, примеры из Пайнли): анкета показывает, какие блоки нужны команде и насколько глубоко.

Страница отправляет ответы в Google-таблицу «Pinely MS-Ops анкета — ответы» (лист «ответы») через Apps Script после каждого вопроса и в финале. Колонки под новые поля таблица добавляет сама. Строка человека обновляется по `sid`, поэтому видно и тех, кто бросил на середине (колонка `last_screen`, `status = partial`). Копировать и пересылать ничего не нужно.

Адрес приёмника прописан в `CONFIG.ENDPOINT`. Если код `.gs` меняется, его вставляют в Apps Script таблицы и выпускают новую версию того же развёртывания: «Управление развертываниями» → карандаш → «Новая версия». Адрес при этом не меняется.

## Режим разработчика (`?dev=1`)

- Жёлтая панель сверху. «Правка текстов: ВКЛ» — клик по любому тексту открывает окно: новый текст (сразу виден на странице) и пометка для Claude.
- «Пометка к экрану» — замечание про экран целиком: анимацию, порядок, вёрстку.
- Выпадашка переходит на любой экран, ветвление не мешает.
- Правки хранятся в браузере и сразу уходят в таблицу на лист `dev_notes`. Ответы из dev-режима помечаются `dev` и в декодере по умолчанию скрыты.
- Перед запуском убрать: режим включается только параметром `?dev=1`, людям ссылку без него. Код можно вырезать позже.

## Что править в конфиге

Всё лежит между `/*CONFIG-START*/` и `/*CONFIG-END*/` в `index.html`: `STRINGS`, `FUN_NAMES`, `OPTIONS`, `FEATURES`, `TRAFFIC_CARDS`, `TRAFFIC_REFERENCE`, `AUTOMATION_TOPICS`, `EXAMPLES`, `SESSION_BLOCKS`. Значения `id` не менять: по ним ответы лежат в таблице.

Эталон светофора: `TRAFFIC_REFERENCE = {director_passport:'red', …}`. Декодер подсвечивает расхождения.

## Декодер

Откройте `decode.html`, введите ключ `READ_KEY` из `.gs` и нажмите «Загрузить». В декодере: таблица по людям, сводка по каждому вопросу, свободные ответы, правки из dev-режима, кнопка «Скачать CSV». Резервный путь: вставить колонку `raw_json` с листа «ответы» вручную.
