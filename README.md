## Как сохраняются ответы

Страница отправляет ответы в Google-таблицу через Apps Script после каждого вопроса и в финале. Строка человека обновляется по `sid`, поэтому видно и тех, кто бросил на середине (колонка `last_screen`, `status = partial`). Копировать и пересылать ничего не нужно.

Пока `CONFIG.ENDPOINT` в `index.html` пустой, ответы никуда не уходят. Как поставить приёмник, написано в шапке `.gs`-файла. Полученный URL `/exec` вписывается в `CONFIG.ENDPOINT`.

## Режим разработчика (`?dev=1`)

- Жёлтая панель сверху. «Правка текстов: ВКЛ» — клик по любому тексту открывает окно: новый текст (сразу виден на странице) и пометка для Claude.
- «Пометка к экрану» — замечание про экран целиком: анимацию, порядок, вёрстку.
- Выпадашка переходит на любой экран, ветвление не мешает.
- Правки хранятся в браузере и сразу уходят в таблицу на лист `dev_notes`. Ответы из dev-режима помечаются `dev` и в декодере по умолчанию скрыты.
- Перед запуском убрать: режим включается только параметром `?dev=1`, людям ссылку без него. Код можно вырезать позже.

## Что править в конфиге

Всё лежит между `/*CONFIG-START*/` и `/*CONFIG-END*/` в `index.html`: `STRINGS`, `FUN_NAMES`, `OPTIONS`, `TASK_CARDS`, `TRAFFIC_CARDS`, `TRAFFIC_REFERENCE`, `CONTEXT_ITEMS`, `CONTEXT_REFERENCE`, `PROMPT_OPTIONS`, `VERIFY_TEXT`, `FEATURES`, `DEEP_TOPICS`. Значения `id` не менять: по ним ответы лежат в таблице.

Эталоны: `TRAFFIC_REFERENCE = {director_passport:'red', …}`, `CONTEXT_REFERENCE = ['project_instructions', …]`. Декодер подсвечивает расхождения.

## Декодер

Откройте `decode.html`, введите ключ `READ_KEY` из `.gs` и нажмите «Загрузить». В декодере: таблица по людям, сводка по каждому вопросу, свободные ответы, правки из dev-режима, кнопка «Скачать CSV». Резервный путь: вставить колонку `raw_json` из таблицы вручную.
